02Business model

Hey Otto is a one-person AI and marketing consultancy in Denmark, run by its owner, Kasper Schrøder Asmussen. Hey Otto helps companies use AI in their marketing, for example with analysis and reporting built on their own data. We sell our services through our own website, www.heyotto.dk.

We use Google Ads only to advertise our own website, heyotto.dk, which we own. We do not manage Google Ads for clients or for anyone else, and HeyOtto OS will never be connected to another company's Google Ads account. The manager account we use for API access is linked only to Hey Otto's own Google Ads account.

03Tool access and use

HeyOtto OS is Hey Otto's own internal web app. Today it is used to plan projects and keep track of working capacity. We want to add Google Ads to it, so that Hey Otto's campaigns can be built and followed up in the same place.

  • One user only: the tool is used by Kasper Schrøder Asmussen, the owner of Hey Otto. There are no other users.
  • Private and password-protected: the app runs at heyotto-os.netlify.app behind a password login. A browser stays signed in for at most 90 days, and sign-in is blocked for 15 minutes after 10 wrong passwords.
  • No outside access: no clients, agencies or other third parties can use the tool or see the reports it makes. The tool is not offered, sold or licensed to anyone.

04Tool design

HeyOtto OS is a web app hosted on Netlify. The page in the browser only shows the interface. All calls to the Google Ads API are made on the server, by Netlify Functions, and never from the browser.

How HeyOtto OS connects to the Google Ads API.

Reporting

Once a day, a scheduled server function pulls performance metrics from the Google Ads API and saves them in the app's own storage (Netlify Blobs). The dashboard reads from that storage. Kasper can view performance at account, campaign, ad group, ad and keyword level, for different time periods (for example the last 7 days, the last 30 days or a calendar month). A Refresh now button runs the same sync on demand.

Campaign building

Kasper builds Search campaigns in a step-by-step form in HeyOtto OS: campaign name, daily budget, location and language targeting, ad groups, keywords, and responsive search ads (headlines, descriptions and a final URL on heyotto.dk). When he submits the form, the tool creates the budget, campaign, targeting, ad groups, keywords and ads through the API.

Every new campaign is created as Paused. Nothing goes live and no money is spent until Kasper has reviewed the campaign and clicks Enable himself. The tool can also pause or enable an existing campaign, but only when Kasper clicks the button. There are no automated rules or scripts that change ads on their own.

Credentials and volume

Kasper authorises HeyOtto OS once with his Google account through Google's OAuth 2.0 consent screen. The developer token, OAuth client ID and secret, and refresh token are stored as environment variables in Netlify. They are only used on the server and are never sent to the browser or saved in the source code. The tool makes a small number of API calls: one sync a day, plus the calls made when Kasper builds, pauses or enables a campaign.
