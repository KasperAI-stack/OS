# Brand

Guidelines, tone-of-voice, and brand assets that every agent should check before producing customer-facing content.

Two brands live here — pick the one the deliverable is for:
- `guidelines.md` — **Africa Tours** visual identity (colors, fonts, logo notes).
- `hey-otto/` — **Hey Otto** visual identity: `guidelines.md` (written rules and tokens), `brand-book.html` (the source brand book), and the logo, icon and Otto mascot as SVG. The `dashboard/` (HeyOtto OS) uses this one.

Suggested additions:
- `tone-of-voice.md` — voice, do's/don'ts, example copy.
